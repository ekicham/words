# 专注时长循环与实时农历时钟

1. 使用现有 SQLite items 追加轮次字段，完成一轮后在同一事务中追加下一轮。截止时间不变，优先本次范围中最近一次答错、提示或跳过的词；无薄弱词时循环原范围。保留原始答题记录、请求去重和只读回看。
2. 首轮正确率单独统计，成功词数去重；练习页面按当前轮显示进度，报告与 CSV 标明轮次和巩固次数。
3. 顶栏显示本机实时年月日、星期、时分秒及对应干支生肖年、农历月日。使用浏览器原生 Intl 中国农历，无额外依赖；兼容窄屏。
4. 先补临时库回归验证循环、错词优先、不重复、超时、重试、迁移；实际浏览器验证跨轮输入、计时、刷新恢复、日期秒更新、春节及闰月。生产数据库升级前备份，核对原记录保留。
