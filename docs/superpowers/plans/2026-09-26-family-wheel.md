# 亲子幸运转盘

**目标：** 点击首页星星卡进入转盘，每次 200 星，八种亲子活动等概率且每次中奖，保存奖品及完成状态。
**实现：** 原生 SVG + Web Animations，无新依赖。累计星星继续由已完成答题计算；可用余额为累计减去抽奖记录的消耗。仅新增 rewards 表，唯一抽奖编号负责幂等，事务内校验余额并保存结果。家人完成活动后可标记已兑换。
