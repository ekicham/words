# Word Isle Implementation Plan

**Goal:** 交付可在本机使用的教材背词软件，SQLite 持久保存词库与学习记录。
**Architecture:** Python 标准库 HTTP 服务和 SQLite；浏览器原生 HTML/CSS/JavaScript；macOS 本地语音缓存，其他系统使用浏览器语音。只监听 127.0.0.1。
**Tech Stack:** Python 3.9+、SQLite、Web Audio/Speech Synthesis，无应用第三方依赖。

- [x] 教材数据：核对 ChinaTextbook 人教 PEP 六上附录，保留版本、页码、来源和校验信息。通过 JSON 导入扩展任意出版社/年级/学期，未收录不假冒覆盖。
- [x] 数据和练习：app.py；先运行 test_app.py 验证缺失，再实现遮词、随机不重复、尝试记录、事务去重、绝对截止时间、刷新恢复、历史报告及错词重练。
- [x] 地区推荐：省份选择；IP 服务超时降级；浙江推荐人教 PEP，版本仍由学生确认。不保存 IP。
- [x] 界面：static/index.html、style.css、app.js；教材准备、拼写练习、报告、历史、词库导入；连击、星星、里程碑。
- [x] 语音：英文和中文连续播放；本机缓存与浏览器回退；失败明确提示，重播与静音。
- [x] 验证：python3 test_app.py；真实浏览器完成首次/二次答对、提示、跳过、结算、刷新、导入和小屏检查；单独临时数据库避免污染真实学习记录。
- [x] 交付：启动.command、启动.bat、README.md、验收记录；启动并打开本机软件。

统计口径：首次正确率=无提示首次答对词数/有提交词数；二次纠正率=无提示恰好第二次答对词数/首次提交错误词数；另列提示、跳过和未完成，分母为零显示“—”。

验收结论见项目根目录 `验收记录.md`。照片中的新版六上已找到官方在线阅读及音频，查找结果见 `教材查找结果.md`；后续已按官网导入计划加入独立的官网版词库，原存档旧版及记录保留。
