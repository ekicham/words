# 官网人教 PEP 词库导入计划

**Goal:** 将官网当前列出的人教 PEP 小学英语词库加入默认 SQLite，在出版社菜单中独立选择，保留旧词库和全部学习记录。
**Architecture:** 复用 app.py 的词库校验和种子导入机制；新增独立 id 的 data/books JSON，保存来源清单；不增加应用依赖。
**Tech Stack:** Python 标准库、SQLite、现有浏览器界面。

- [x] 从官网目录核对 PEP 三至六年级全部条目（共 9 条，五下两版），排除精通等其他体系。
- [x] 读取本次 8 册单元词表，核对英文、中文、单元、页码；按每册真实版次记录，不把官网旧版称为新审定版。
- [x] 使用 SQLite backup 保存正式库，记录旧 books/words 和 sessions/items/attempts/requests 校验摘要。
- [x] 在临时 SQLite 中先检查新旧并存、教材数量和重启幂等性；用独立 id 和新 publisher 导入。
- [x] 默认库仅新增；按旧数据摘要验证没有更改历史。
- [x] 浏览器检查出版社、年级、学期/版本和新词实际练习；更新来源与验收记录。

范围调整：用户明确要求六年级下册暂不导入，官网目录该项标为 deferred_by_user。最终新增 8 册、1,032 个词条（7 册新版及官网旧版五下），保留原 8 册、844 个词条及全部学习记录。验收证据见根目录 `验收记录.md` 和 `output/official-import.json`。

官网若出现人工验证，停在验证处；不伪造来源头或绕过验证。不完整词表不以完整教材导入。
