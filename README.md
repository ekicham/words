# 词屿 Word Isle

本地电脑版背单词软件：选择教材、年级、学期 → 听英文和中文 → 补全单词 → 查看学习报告。

## Tencent EdgeOne 在线版（本分支）

`codex/tencent-edgeone` 支持 EdgeOne Makers 静态站点 + Python 云函数 + MySQL 8。邀请码注册，每人独立保存学习、星星、奖品和录音报告。部署步骤见 [EdgeOne 部署说明](docs/EdgeOne部署说明.md)。需自行准备可从云函数访问的 MySQL，账号和记录不会从 Cloudflare 自动迁移。

Cloudflare 版本保留在 `main` 分支；继续部署 Cloudflare 请选择 `main`，不要使用本分支的构建命令。桌面版业务代码保留；下面的本机数据、无需账号及本地模型说明仅适用于桌面版。

## 打开软件

- **macOS 安装版**：打开 `dist/macos/词屿-1.4.1-macOS-Universal.dmg`，将“词屿”拖入 Applications，推出 DMG 后从应用程序启动。支持 macOS **12.3+**，包含 Apple 芯片与 Intel 运行代码，无需另装 Python，也不需要终端窗口。
- 安装版尚未进行 Developer ID 签名和 Apple 公证。首次被系统阻止时，尝试打开后到“系统设置 → 隐私与安全性 → 仍要打开”；详见 `macos/安装与使用说明.txt`。企业受管理设备可能需要管理员批准。
- 安装版数据在 `~/Library/Application Support/WordIsle/`，更新应用不会覆盖记录。分发包不含本机已有学习数据。菜单“帮助”可打开数据目录和使用说明。
- **源码版 Mac**：双击 `启动词屿.command`，或在当前目录运行 `python3 app.py --open`。
- **Windows 7 旗舰版 64 位便携包**：完整解压 `dist/windows/词屿-1.4.1-Windows7-x64-r2.zip`，双击 `Start-WordIsle.bat` 或 `启动词屿.bat`。内置 Python 3.8.10，无需另装 Python。需要 Win7 SP1、KB2533623（或后续替代更新）、UCRT，以及 Chrome 109 / Edge 109 / Firefox 115 ESR；不支持 IE。尚未在 Win7 真机执行，环境要求和故障排查见 `windows/使用说明.txt`。
- Windows 包学习数据保存在 `%LOCALAPPDATA%\WordIsleWeb\`，升级程序包不会覆盖记录。浏览器朗读需安装对应语言的系统语音；腾讯云评测保留，OpenPronounce 本地组件仍仅支持 Apple 芯片 macOS。
- 源码版地址：<http://127.0.0.1:8765>。保留启动窗口；按 Ctrl+C 停止。若已启动，直接打开地址即可。安装版自动选择空闲本机端口，退出应用自动停止服务。
- 安装版无需另装 Python 包。单词学习不需要账户；发音评分可选 OpenPronounce 本地模型或自行配置腾讯云。源码版的本地引擎需先运行 `scripts/build_openpronounce.sh` 安装固定依赖。只监听本机地址，不向局域网或公网开放。

## 可以做什么

- **音标学习**位于单词探险之前：48 组英美对照（20 组元音、24 个辅音、4 组组合音），切换口音后播放对应的剑桥真人录音。组合音及部分美式对应音使用例词示范并标注。权威点读需联网，用户提供的歌谣视频与 MP3 随包离线使用，视频不随口音切换。点击“全屏播放”放大观看，按 Esc 退出并保留播放进度。
- **发音练习**提供随机 10 项 / 完整 48 项：显式开启麦克风，录制 0.5–8 秒，回听后交给所选服务评分。腾讯云读目标音，本地引擎读完整例词。完成或提前结束会保存评分、平均分、有效评分数、跳过和未完成项，可回听录音、导出 CSV、删除本次录音及报告。低于 80 分仅为本应用练习建议；未配置、运行失败和缺少有效分数不会生成假成绩。
- **OpenPronounce 本地评测**：设置中可选本地/腾讯云，切换保留凭证，测试固定记录所选引擎。本地模式读完整例词，报告含参考分、识别文本及音素；不宣称孤立音标准确率或英美口音鉴定。运行组件已随包提供，仅支持 Apple 芯片、macOS 14+；首次在设置中下载约 2.4 GB 模型，之后可离线评分。原 Universal 主应用和腾讯云仍支持 Intel/macOS 12.3+。
- **设置 → 音标发音评测 → 腾讯云配置**配置 SecretId / SecretKey 及可选 SoeAppId。密钥存入用户数据目录 `phonetics-service.json`（权限 0600），不回显、不打包。录音与报告存在 SQLite；仅腾讯云模式点击提交时上传，服务需联网并可能产生费用。本地模式不上传录音，也不会因失败自动转到腾讯云。所选英美口音用于示范，SOE 使用通用英语音素模型，不能视作英美口音鉴定。来源及评测口径见 `data/sources/phonetics-learning.md` 和 `data/sources/openpronounce.md`。

- 首页“练习方式”支持 **提示拼写 / 英文听写 / 中文听写**。听写隐藏全部字母、音标和中文，所选语言朗读两遍，间隔约 0.8 秒，第一遍读完即可输入。
- **设置 → 听写设置**：两种听写共用。自动模式可设置每词 **1–300 秒**（默认 15 秒），第二遍结束后开始计时，写满自动判分；到时立即进入下一词，空白或未写完记录为“超时答错”。手动模式无每词倒计时，写满后可修改，按 **Enter** 提交并自动进入下一词；第二遍播放时按 Enter 会在朗读结束后提交。正确显示约 0.65 秒，提前答错显示答案约 2 秒，无需再次按键。
- 听写设置自动保存，下次开始练习生效；当前练习固定使用开始时的设置。刷新或重启保留设置、草稿与进度，自动模式不会重置倒计时。总练习时长独立设置，到时允许完成当前词，之后显示报告。听写需要声音，会忽略提示拼写的静音设置；朗读失败不计时、不扣分，可重试。
- 听写报告和 CSV 区分正确、拼写错误、超时答错，并标注练习方式；超时未写完进入错词。错词按不同练习方式分别维护，提示拼写成功不能清除听写错词；错词页可选择练习方式。累计完成词数和星星汇总各模式的成功作答，不代表独立听写掌握度。

- 点击首页星星卡进入“亲子幸运转盘”，每次消耗 **800 星**，八种亲子活动等概率（各 12.5%），每次都会获得一份活动：桌游、散步、电影、做点心、故事接龙、手工、运动和家庭音乐会。奖品自动保存，和家人完成后可标记已完成；重复抽到的活动分别保留。支持转盘动画及系统减少动态效果偏好。在“设置 → 亲子转盘奖品”可从16个图标中选择八格奖品，名称和活动说明随图标自动匹配，无需输入；点击“保存奖品设置”后生效；已获得奖品保留抽取时的内容和实际消耗。
- 首页“累计已完成”和“今日已完成”可点击查看学习明细：最近学习日期、单词、音标、中文、单元、学习频次、学期、年级、教材和地区。相同英文跨教材、跨练习只计一个；同词的不同教材及地区出处分别保留。明细页可切换累计/今日，窄屏表格可左右滚动。
- 首页每天显示一句中英文名人名言，同一本机日期保持一致，跨日轮换。内置 12 句离线名言，12 天一轮，作者接在英文句子后，可点击查看出处，译文为本项目意译。移除首页地区说明与底部学习地图，仍可用“练习范围”选择单元。

- 顶栏每秒更新本机公历日期、星期与时分秒，下方显示对应的干支生肖年及农历月日；春节换年、闰月由浏览器原生中国农历换算。
- 参考 Apple HIG 的 Liquid Glass 网页界面：玻璃侧栏、工具栏与操作控件，独立清晰的阅读表面；跟随系统深浅色、减少动态效果、减少透明度和增强对比度偏好。浏览器实现不等同于 macOS 原生材质。
- 左侧“设置”集中调整朗读声音与语速，自动保存偏好；返回练习后生效。
- 提示拼写学习区左右按钮查看上一个/下一个。回看已学词只读展示，不重复计分；当前未完成的词点“下一个”按跳过记录。

- 首次打开时按 IP 自动推荐省份，保存定位尝试和选择；之后不会重复定位，界面不设定位按钮。定位失败、代理出口或不在中国时可以手动选。当前只内置有来源依据的浙江 → 人教 PEP 推荐，其他省份不会伪造统一出版社映射。
- 选择出版社、年级、上下册和单元，以及“顺序学习 / 随机学习”。顺序学习按单元编号排列，单元内保持教材词表导入顺序；随机学习一轮不重复。模式会记住，已开始的练习保持原出题次序。每轮完成后，时间未到就继续：优先练习本次范围中最近一次答错、提示或跳过的词；这些词首次独立答对后，循环原范围。顺序模式的巩固词仍按教材顺序，随机模式每轮不重复。
- 提示拼写保留前 1–3 个字母，其余遮住。例如 `Monday → Mon___`，光标直接停在下划线处，输入 `day` 自动检查并跳到下一词；没有下方独立输入框。支持删除、光标移动、点击字母格及答错重输。短词至少隐藏一个字母。短语只需补缺失字母，空格、连字符等已显示的标点不需输入；忽略大小写。
- 点击“开始单词探险”或“继续探险”进入大字全屏。按 **Esc** 或“退出全屏”恢复普通页面，进度保留、计时继续；需要提前结束时点击“结束练习并查看报告”。浏览器不允许全屏时使用满窗口专注布局，Esc 同样可退出。
- 提示拼写以及听写交卷后，单词下方显示离线音标：官网新版六上按教材词表核对，短语未注部分用英式参考补全；其他教材沿用美式参考。来源说明放在音标悬停提示，无教材音标的中文地名保留拼音。来源与具体口径见 `data/sources/phonetics.md`。外部词库未收录的词形显示“音标待补充”。
- 提示拼写中，英文和中文依次自动朗读；支持重播、静音，以及 **0.75× / 1× / 1.25× / 1.5×** 语速。在设置中切换后，继续探险时按新速度朗读，并记住选择。Mac 使用系统 Samantha / Tingting 生成本机音频，缓存后重复使用；调速保留音高。其他系统尝试浏览器已安装的中英文语音，缺失时显示提示。合成语音不是教材原版录音。
- 15 / 30 / 45 分钟或自定义 1–180 分钟。学完一轮不会提前结束，按真实截止时间结算或手动结束；切换窗口、刷新、关闭页面不暂停计时。再次打开可继续剩余时间，已超时则在学习足迹查看结果。
- 答错重试、提示、跳过；连击和星星；按最新一次实际练习结果维护错词巩固，首次独立答对后移出。
- 每次输入逐条保存在 SQLite。历史报告按轮次包含原始输入、次数、正确与否、是否提示，并可导出 CSV。
- 从界面导入其他教材的 JSON 词库；下载模板可查看格式。验证整册后一次性导入；无效文件不会部分写入，已有相同 id 不会被覆盖。

## 统计口径

首页星星卡显示**可用星星 = 累计获得 − 抽奖消耗**。转盘页同时显示累计、已用和可用；既有星星直接可用，抽奖不改写学习报告中的奖励。余额不足不能抽奖；扣星和保存奖品在同一事务完成，刷新、网络重试与重复提交不会重复扣星。

首页完成数量按英文拼写去重（忽略大小写和多余空白）；成功拼写过一次即计入，含提示后答对和未结束练习。今日以每次实际答对的本机日期为准，不按整次练习的开始日期。详情学习频次为当前范围内成功答题次数，跨轮重复练习增加频次，同一题重复请求不重复计次；最近学习日期按各教材/单元/学习地区的最近完成时间显示。这些统计由既有提交记录计算，无需重新学习或迁移记录。

提示拼写的正确率以及提示、跳过、未完成仅统计首轮，后续巩固不改写首轮结果。报告另外列出完成轮数、累计练习次数（答对或跳过）和巩固答对次数（第二轮起的答对次数）。

| 指标 | 定义 |
| --- | --- |
| 首次独立正确率 | 无提示且第一次答对的词数 ÷ 有过提交的词数 |
| 二次纠正率 | 无提示且恰好第二次答对的词数 ÷ 第一次提交错误的词数 |
| 两次内独立掌握率 | 无提示且前两次内答对的词数 ÷ 有过提交的词数 |
| 成功拼出 | 跨轮按词条去重的答对词数，包含提示后答对 |
| 提示 / 跳过 / 未完成 | 单独列出；未提交的单词不计入正确率分母 |

填满缺少的字母或主动按 Enter 检查算一次提交。分母为零显示“—”，不会显示虚假的 0% 或 100%。有提示的词不计入独立正确。首次、二次、更多次、提示后答对分别得 10、6、4、2 星；星星是练习奖励，不是能力测评。教材中同一拼写在不同单元、不同义项出现时，按不同词条处理。

- 仓库提供的是教材 PDF，不是结构化词库；公开 GitHub 仓库本身不等同于教材版权许可。此项目没有打包原始教材 PDF，发布或商业分发前仍需核查相应内容授权。

## 数据和隐私

- 以下路径为源码版。macOS 安装版的数据库和音频缓存保存在 `~/Library/Application Support/WordIsle/`；教材和音标来自应用包内只读资源。安装版偏好使用 macOS 应用设置保存，每次启动更换端口不会丢失设置。
- `data/words.sqlite3`：教材、词条、学习会话、每次输入、防重复提交记录，以及抽奖奖品、消耗与完成时间。
- `data/audio/`：本机生成的语音缓存，可以在停止服务后删除并自动重建。
- `data/books/`：内置词库 JSON；首次启动自动导入。已存在的词库不会被启动过程覆盖。
- `data/sources/`：来源清单与原始附录提取文本，供核对。
- `data/phonetics.json`：离线读音子集；不改变原词条和历史答案。
- `data/backups/`：本次导入前的 SQLite 完整备份；`output/official-import.json` 记录导入前后数量及旧数据校验结果。
- 浏览器仅保存地区、课本、时长、静音等偏好；成绩以 SQLite 为准。当前是一个本机学习档案，未实现多人账号。
- 首次访问会向 [ipapi.co](https://ipapi.co/api/) 查询网络出口 IP 对应省份；服务方会看到网络出口 IP。软件不持久保存该 IP，也不发送学生答案。定位网络不可用时其余本地功能仍可运行。
- 备份：停止服务后复制整个 `data` 文件夹。不能在服务运行中只复制 SQLite 文件而忽略可能存在的日志文件。

## 开发和验收

Windows 包重建：`python3 scripts/build_windows.py`；校验：`python3 -m unittest test_windows`。构建脚本下载并校验官方 Python 3.8.10 x64 嵌入式 ZIP，按资源白名单打包，不带入数据库、缓存、密钥或本地模型。`test_windows` 在构建主机上运行解压后的服务、读写及重启检查，不代表 Windows 7 真机验收。

```sh
python3 test_app.py
python3 test_catalog.py
python3 test_rewards.py
python3 test_macos.py
python3 test_dictation.py
python3 -m unittest test_phonetics test_openpronounce
python3 app.py --open
```

macOS 安装包重建：`./scripts/build_macos.sh`。构建机器需有 Apple 芯片、macOS 14+、Xcode Command Line Tools 和网络；脚本校验并解包 Python 官方 Universal2 运行环境，在项目 `.build/macos/` 中安装固定版本构建依赖，不修改系统 Python。首次还会构建独立本地评测组件；修改该组件后先运行 `./scripts/build_openpronounce.sh` 再重建主应用。输出 `.app`、DMG 和 `SHA256SUMS.txt` 到 `dist/macos/`。目标设备安装无需这些开发工具。

最低系统设为 12.3，是因为当前界面的 `<dialog>` 等 WebKit 功能从 Monterey 12.3 随附的 Safari 15.4 起可用。原生窗口在本机 macOS 15.7.5 实测；Intel 后台通过 Rosetta 执行检查，尚未在独立 Intel Mac 或 macOS 12.3 真机验收。详细记录见 `macos/验收记录.md`。

可选浏览器验收使用已安装的 Playwright（无需修改应用依赖）：

```sh
NODE_PATH=/path/to/node_modules node test_dictation_browser.cjs
NODE_PATH=/path/to/node_modules node test_browser.cjs
NODE_PATH=/path/to/node_modules node test_catalog_browser.cjs
NODE_PATH=/path/to/node_modules node test_learning_browser.cjs
NODE_PATH=/path/to/node_modules node test_navigation_browser.cjs
NODE_PATH=/path/to/node_modules node test_completed_browser.cjs
NODE_PATH=/path/to/node_modules node test_rewards_browser.cjs
NODE_PATH=/path/to/node_modules node test_prize_settings_browser.cjs
```

浏览器验收使用临时数据库与 8767–8774 端口，结束后清理临时库；截图和结果在 `output/playwright/`。设置 `HEADED=1` 可显示学习控件验收的 Chrome 窗口。`app.py` 提供 SQLite 和本机接口，`static/` 为原生浏览器界面。更多验证结论见 `验收记录.md`。
